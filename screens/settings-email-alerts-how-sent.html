How alerts are sent
Only when a status changes
For example from OK to Warning, or from Alarm back to OK. You get no email while a status stays the same.
One email for each upload
The instrument uploads its readbacks together. If several readbacks change in one upload, they are in one email.
Software updates come separately
Software versions are a different upload, so a software update is its own email.
